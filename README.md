
# Excel-Based NGO Research Project

## Project Overview
This project involves researching and organizing information about NGOs using Google Sheet. The objective is to compile relevant information into a structured spreadsheet that is easy to review and use.

## Tools Used
- Google Sheet

## Work Performed
- Collected and organized NGO-related information.
- Structured the data into a spreadsheet for easy reference.
- Arranged information in a clear and readable format.
- Reviewed the collected information for consistency.

## Project Files
- `NGO_Research.xlsx` – Excel spreadsheet containing the collected and organized information.

## Key Learning
This project helped me gain practical experience in data organization, spreadsheet management, and presenting information in a structured format.
